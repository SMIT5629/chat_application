#  Real-Time Chat Application

A real-time chat application built using **Next.js, Node.js, Express.js, and Socket.IO**. The frontend is developed using Next.js with the help of Antigravity, while the backend handles real-time communication using Socket.IO.

##  Features

- Real-time messaging using Socket.IO
- Modern and responsive user interface
- Frontend built with Next.js
- Backend powered by Node.js and Express.js
- Instant communication between connected clients
